# License-text provenance

The unmodified `GPL-2.0-only.txt`, `GPL-3.0-only.txt`, `LGPL-2.1-only.txt` and `NCSA.txt` texts were retrieved from SPDX license-list-data tag `v3.27.0`, `text/<identifier>.txt`:
https://github.com/spdx/license-list-data/tree/v3.27.0/text

The pinned Termux packages reference these shared license texts through symlinks; package symlinks/scripts are intentionally never extracted or executed by the build. These local texts are packaged alongside upstream package copyright notices, LLVM and translator notices, import-tool notices and `android/TOOLCHAIN-NOTICES.md`.

License text inclusion does not replace corresponding-source or other distribution obligations; see the toolchain notices before publishing binaries.
